# Measurement Example

A useful observation record should be reproducible and scoped.

| Field | Example |
|---|---|
| Engine | example engine |
| Query/prompt | a defined test query |
| Market | RO |
| Language | Romanian |
| Observation date | YYYY-MM-DD |
| Brand mentioned | yes/no |
| Source cited | yes/no |
| Referral observed | yes/no |
| Conversion observed | yes/no |

Do not infer a citation from a mention, or a conversion from a referral. See https://niculae.info/blog/ai-citation-share-of-voice/ and https://niculae.info/blog/ai-referral-attribution/ for the maintained source material.
