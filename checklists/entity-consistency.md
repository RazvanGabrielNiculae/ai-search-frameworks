# Entity Consistency Checklist

- [ ] Canonical person/organization name is stable.
- [ ] Canonical URL is stable.
- [ ] Author and publisher relationships are explicit.
- [ ] Short descriptions do not contradict one another across owned properties.
- [ ] Structured data represents visible, supportable facts.
- [ ] External profile links are verified before adding `sameAs`.
- [ ] Conflicting or stale facts are documented for correction.
